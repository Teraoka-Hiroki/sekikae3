# 席替えアプリ (Classroom Seating Optimizer)
### 海星高校 自由探究ゼミ＠K

機械学習（K-Meansクラスタリング）および組合せ最適化手法（焼きなまし法: Simulated Annealing）を活用し、クラスの「席替え」を自動的・かつ最適に行う完全ブラウザ動作型のWebアプリケーションです。

---

## 🌟 主な機能

### 1. 直感的なデータ読み込み & 動的適応
- **Excel (`.xlsx`, `.xls`) / CSVファイル読み込み**: ドラッグ＆ドロップまたはファイル選択で生徒名簿を取り込みます。
- **動的カラム・人数適応**: 特性項目の数や生徒人数が何名であっても、自動的に検知して適応します。
- **テスト用サンプルデータ**: フォルダ内の `student.xlsx`（国語、数学、理科、社会、英語、積極性、協調性の評価データ含む30名分）をドラッグ＆ドロップして即座にテスト可能です。

### 2. 教室配置カスタマイズ & 直感的な固定席指定
- **列数・行数の自由入力**: 教室の列数（横の席数）を入力すると、総人数から最適な行数を自動計算して2D座席マップを描画します。
- **席ごとの生徒番号入力による固定席機能**: 教室の各座席カードにある「生徒No:」入力欄に直接生徒番号（例: `3` や `15`）を入力すると、その座席に生徒が固定ピン留め指定されます。固定された生徒は最適化中も移動せず、周囲のフリー席に非固定の生徒のみが最適配置されます。

### 3. 多次元機械学習 & 組合せ最適化アルゴリズム
- **Zスコア標準化**: 各教科の成績や性格評価などの次元の尺度（平均・標準偏差）を均一に揃えます。
- **K-Meansクラスタリング ($K=6$)**: 多次元の特性ベクトルに基づき、生徒を6つの類似性グループ（クラスタ）に自動分類します。
- **タブ1【異質分散配置 (ランダム分散)】**:
  - 隣り合う席同士の特性の類似度を最小化（＝距離を最大化）し、かつ「同じクラスタの生徒同士が隣り合わない」制約を満たすよう、焼きなまし法で大域最適化します。
- **タブ2【同質グループ配置 (同質配置)】**:
  - 特性が近い生徒や同じクラスタの生徒が近い位置（同一ゾーン）に集まるように配置します。グループ学習等に最適です。

### 4. プログレスバー & 演出・視覚化
- 計算時間がかかる焼きなまし法のイテレーション進捗状況（0%〜100%）、現在の温度 $T$、評価スコアをリアルタイムでプログレス表示します。
- UIフリーズを防ぐ非同期イテレーション制御を行っています。

### 5. デザイン & エクスポート
- **スタイリッシュなダークモード**: Slate / Cyan を基調としたモダンなグラスモーフィズムUIデザイン。
- **ロゴヘッダー**: 「海星高校 自由探究ゼミ＠K」プロファイルロゴ（`kaisei_logo.jpg`）をヘッダーに配置。
- **印刷 & データ出力**: 座席配置表の印刷（PDF保存）対応、およびCSVファイルエクスポート機能を搭載。

## 📐 数理モデルと最適化理論

### 1. Zスコア標準化
各生徒の特性評価値を標準化します。
- `標準化スコア (z) = (個人の評価値 - 全体の平均値 μ) / 標準偏差 σ`

### 2. K-Means クラスタリング
多次元特徴ベクトルに対して、クラスタ内二乗和 (SSE) を最小化するように6個の重心を求めます。
- `目的関数 J = ∑ (生徒の特性ベクトル - 所属クラスタの重心)² を最小化`

### 3. 焼きなまし法 (Simulated Annealing)
物理の金属冷却過程を模した大域的最適化手法です。改悪となる状態変化も確率 $P$ で受容します。
- `Metropolis受容確率 P = exp(- エネルギー変化 ΔE / 現在温度 T)`

## 🚀 デプロイ・実行方法

本アプリは外部バックエンドサーバーを必要とせず、完全なフロントエンド（HTML/CSS/JavaScript）で動作します。

### 1. Vercel でのデプロイ（推奨）
1. [Vercel](https://vercel.com/) にログインし、「Add New...」>「Project」を選択します。
2. GitHub の `Teraoka-Hiroki/sekikae3` リポジトリを選択（Import）します。
3. 設定項目:
   - **Framework Preset**: `Other`
   - **Root Directory**: `./`（デフォルトのまま）
   - **Build and Output Settings**: すべて空欄 / デフォルトのまま（ビルド不要）
4. 「**Deploy**」ボタンをクリックします。数秒で公開URLが発行されます。

### 2. Local での実行
1. `index.html` をブラウザでダブルクリックして開くだけです。サーバー起動やインターネット接続は不要です。

### 3. GitHub Pages でのデプロイ
1. GitHub リポジトリの **Settings** > **Pages** を開きます。
2. Source を `Deploy from a branch` に設定し、`main` ブランチの `/ (root)` を選択して **Save** します。
