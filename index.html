数理モデルと最適化アルゴリズムの解説

本アプリで採用している多次元クラスタリングおよび組合せ最適化の理論解説

1. 特性データの標準化 (Z-Score Normalization)

各生徒の評価データ（国語・数学等の教科成績や積極性・協調性など）は、単位やばらつき（スケール）を均一に揃えるため、Zスコア標準化を行います。

標準化スコア (z) = (個人の評価値 - 全体の平均値 μ) / 標準偏差 σ

これによって、満点が異なるテストや基準が違う指標であっても、対等な重みで多次元特性比較が可能になります。

2. K-Means クラスタリング (K = 6)

生徒データは多次元空間上の特徴ベクトルとして表現されます。本アプリでは **K-Means++** アルゴリズムにより、生徒を似た特性を持つ6つのグループ（クラスタ）に分類します。

目的関数 J = ∑ (生徒の特性ベクトル - 所属クラスタの重心)² を最小化

3. 特性ベクトルの距離尺度 (Euclidean Distance)

生徒Aと生徒Bの特性の類似度（差の大きさ）は、多次元ユークリッド距離で計算されます。

特性距離 d(A, B) = √ [ (国語差)² + (数学差)² + (理科差)² + ... + (協調性差)² ]

4. 焼きなまし法 (Simulated Annealing: SA)

席替えの組み合わせ数は爆発的に増加するため（NP困難問題）、物理の金属冷却過程（焼きなまし）を模した確率的探索アルゴリズムを採用しています。

Metropolis受容確率 P = exp(- エネルギー変化 ΔE / 現在温度 T)

計算初期（温度 T が高い状態）では改悪となる配置変換も一定確率で許容し、局所解（ローカルオプティマ）を回避しながら大域的最適解へ収束させます。

5. 各配置モードの評価関数 (Energy / Cost Function)

  • タブ1（異質分散配置）: 隣り合う座席同士で「同じクラスタである場合のペナルティ」および「特性類似度が高い（距離が近い）場合のペナルティ」を最大化するようにエネルギーを最小化し、多様な生徒が混ざり合う配置を実現します。
  • タブ2（同質近接配置）: 同じクラスタの生徒同士が近くの席になり、特性距離が近い生徒が互いに近接するようにエネルギー関数を設計しています。

6. 制約条件（固定席の完全保護）

座席入力欄に生徒番号が指定された席は「固定席」としてロックされます。焼きなまし法のランダム交換ステップから完全に除外されるため、固定された生徒は絶対に移動せず、残りのフリー席に非固定の生徒が最適配置されます。
